Getting started

Follow these steps to get Voicey up and running on your server. You can then consult the other documentation pages to master all the details of how the bot works.

Step 1 : Invite the bot

Add Voicey to your server, then make sure it can create voice channels, modify their permissions, join a voice channel, and write in your log channel.

Invite Voicey

Step 2 : Set up permissions

The minimum permissions needed by the bot are:

  • Create and delete temporary voice channels
  • Modify channel access permissions
  • Join a voice channel to start a recording
  • Write in the configured log channel

Step 3 : Launch the configuration wizard

Use the /configcommand to set the bot's basic parameters.

The quick start is enough to get the bot working on your Discord server, but feel free to read the configuration options in detail.
